# VNAwise Releases

Public download repository for **VNAwise** Android releases.

VNAwise is an Android USB-OTG companion for NanoVNA instruments. It keeps the application source private while making signed APK releases publicly downloadable.

## Downloads

Open the repository's **Releases** section to download the latest signed APK.

## Installation

Download the APK on your Android device, allow installation from your browser or file manager when prompted, and install it normally.

Future updates must be signed with the same VNAwise release key, so keep the installed app if you want in-place upgrades.

## Source code

The VNAwise source repository is private. This public repository is intentionally limited to release distribution and public release notes.
